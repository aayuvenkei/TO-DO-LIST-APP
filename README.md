# 📝 My Task Manager

A simple and clean task management app built with vanilla JavaScript. Helps you keep track of your daily tasks with an intuitive interface.

## About This Project

I built this app to practice my JavaScript skills and create something useful at the same time. It's a straightforward to-do list that saves your tasks in the browser, so they stick around even after you close the tab.

## Features

- Add tasks quickly with a simple input field
- Mark tasks as done with a checkbox
- See your progress with live counters (total, pending, completed)
- Filter tasks by status (all, pending, or completed)
- Remove individual tasks or clear all completed ones at once
- Tasks are saved automatically in your browser
- Clean and responsive design that works on mobile too
- Shows when each task was added

## How to Use

1. Type your task in the input field
2. Click "Add Task" or just press Enter
3. Check the box when you complete a task
4. Use the view buttons to filter your tasks
5. Click "Remove" to delete a task
6. Use "Clear Completed Tasks" to clean up finished items

## Tech Stack

Just the basics:
- HTML for structure
- CSS for styling (with CSS variables for easy customization)
- Vanilla JavaScript (no frameworks needed!)
- LocalStorage API for saving data
